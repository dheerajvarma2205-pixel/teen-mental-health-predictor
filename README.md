## 📋 About
MindGuard is an AI-powered web application that predicts
depression risk in teenagers based on lifestyle habits
and social media usage patterns.

## 🎯 Features
- 🔮 AI Depression Risk Prediction
- 📋 Mental Health Self Assessment Quiz
- 📈 Progress Tracker
- 🎯 Daily Wellness Goals Checklist
- 🌬️ Guided Breathing Exercises
- 🥗 Personalized Diet & Lifestyle Remedies
- 📊 Analytics Dashboard
- 📞 Emergency Helplines

## 🔬 Tech Stack
- Python 3.12
- Scikit-learn (Random Forest Classifier)
- Streamlit
- Plotly
- Pandas & NumPy

## 📊 Model Performance
- Algorithm: Random Forest (Hyperparameter Tuned)
- Accuracy: 85%+
- Dataset: 2,500 teen records
- Features: 11 lifestyle factors
